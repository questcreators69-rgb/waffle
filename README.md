# niharika's internet corner

A personal web page showcasing favorite things, travel memories, an interactive guestbook, and a generator for simple cozy activities.

## Features

- **About & Profile:** Personal intro, current interests, and media links.
- **Interactive Guestbook:** Local storage-backed guestbook for posting and viewing visitor messages.
- **Travel Memories Page:** Photos and videos from Shimla and Kasauli with captions.
- **Wheel of Small Joys:** Random activity generator for simple offline activities.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## Usage

Simply open `index.html` directly in any web browser. No installation or build steps required.
